# Haveno Documentation

Haveno is a decentralized, peer-to-peer exchange for trading Monero (XMR) for fiat currencies and other cryptocurrencies.

There is no central entity. Trades happen directly between users over Tor, and your wallet is created locally so only you have access to your funds.
